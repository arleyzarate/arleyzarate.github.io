RECURSOS | Arley Zarate
Estructura separada: sitio principal y almacén de archivos
Fecha: 09/10/2026

ATENCIÓN: https://github.com/arleyzarate es un PERFIL, no es una página HTML.
Para alojar una página principal de GitHub Pages cree el repositorio:
  https://github.com/arleyzarate/arleyzarate.github.io
La dirección pública será:
  https://arleyzarate.github.io/

1. PÁGINA PRINCIPAL (repositorio arleyzarate.github.io)
   Suba index.html, palabras.js y archivos.js a la raíz.
   Configure Pages para publicar desde la rama principal, carpeta raíz (/).
   No es necesario subir allí las aplicaciones o los archivos técnicos.

2. ALMACÉN DE RECURSOS (repositorio recursos)
   Mantenga en la raíz las utilidades HTML y los archivos LSP, DWG, PDF, etc.
   El repositorio es: https://github.com/arleyzarate/recursos
   Las utilidades HTML se abrirán desde: https://arleyzarate.github.io/recursos/
   Debe conservar la publicación de GitHub Pages para dicho repositorio.

3. FUNCIONAMIENTO
   La página principal consulta los nombres mediante:
     https://api.github.com/repos/arleyzarate/recursos/contents
   La búsqueda parcial, la lista desplegable y los filtros se mantienen.
   Los HTML se abren en otra pestaña.
   Para otros formatos se pregunta Sí o No antes de solicitar la descarga.
   La consulta busca archivos de la raíz del repositorio recursos, no subcarpetas.
   El catálogo se carga al abrir la página. Añadir archivos no requiere editar index.html.

4. EN WINDOWS SIN LOCALHOST
   Puede abrir los archivos de la página directamente desde Windows.
   Si desea que busque archivos locales, colóquelos junto a index.html y ejecute
   actualizar_archivos.bat para regenerar archivos.js antes de abrir la página.
   La apertura local mantiene ese modo de funcionamiento, independiente de GitHub.

5. LIMITACIONES
   La API pública de GitHub puede estar sujeta a límites y fallos de red.
   La URL de GitHub Pages debe estar publicada y actualizada para abrir los HTML.
   El atributo de descarga funciona al compartir el mismo origen web.

DISEÑO Y COMPORTAMIENTOS CONSERVADOS
   - Nombre Arley Zarate y texto Ingrese comando_ intermitente.
   - Búsqueda parcial y navegación con teclado o clic.
   - Exclusión de nombres como index, README, LEAME, actualizar, archivos y palabras.
   - 10 colores oscuros rotativos cada 5 segundos.
   - Columnas verticales con 1.000 palabras de palabras.js.

PRUEBAS DE ESTA ENTREGA
   - Sintaxis JavaScript comprobada con Node.js.
   - Navegador con respuesta simulada de GitHub: búsqueda parcial, exclusiones,
     enlace de HTML, confirmación de LSP y URL de descarga correctos.
   - No se verificó el funcionamiento del repositorio real ni del sitio publicado.
